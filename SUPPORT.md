# Support for OperatorNest open source components

For usage questions, troubleshooting, and help choosing an approach, start a [Q&A discussion](https://github.com/orgs/OperatorNest/discussions/categories/q-a). Include the component name, package version, runtime, what you tried, and a small example with secrets and personal data removed. Maintainers and community members respond as volunteers on a best-effort basis; there is no guaranteed response time.

For reproducible bugs, open an issue in the affected repository:

- [convex-razorpay issues](https://github.com/OperatorNest/convex-razorpay/issues)
- [convex-zoho-cpaas issues](https://github.com/OperatorNest/convex-zoho-cpaas/issues)
- [convex-models-dev issues](https://github.com/OperatorNest/convex-models-dev/issues)
- [convex-web-push issues](https://github.com/OperatorNest/convex-web-push/issues)

For a security vulnerability, use the affected repository's private vulnerability reporting page. Do not post exploit details, credentials, or customer data in issues or discussions:

- [Report privately for convex-razorpay](https://github.com/OperatorNest/convex-razorpay/security/advisories/new)
- [Report privately for convex-zoho-cpaas](https://github.com/OperatorNest/convex-zoho-cpaas/security/advisories/new)
- [Report privately for convex-models-dev](https://github.com/OperatorNest/convex-models-dev/security/advisories/new)
- [Report privately for convex-web-push](https://github.com/OperatorNest/convex-web-push/security/advisories/new)

The `convex-razorpay` repository accepts security reports only through its private reporting flow. For a community conduct concern, see the [Code of Conduct](CODE_OF_CONDUCT.md).
